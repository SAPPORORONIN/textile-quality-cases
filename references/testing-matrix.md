# 美标 AATCC / ASTM / ISO 纺织品与家纺检测标准矩阵速查手册

> **US Testing Standards Protocol Matrix: AATCC, ASTM & Regulatory Testing Quick Reference**

> [!IMPORTANT]
> 表中“常见参考值”是美国零售商/品牌手册中常见量级，用于内部预判，**不是法定限值**。合同验收一律以客户 Tech Pack/测试手册的方法版本、试样方向、洗涤程序与判定规则为准。方法须引用现行版本；已撤销的标准（如 ASTM D434）不得再用作验收依据。

---

## 一、 使用原则
1. **方法与判定分开写**：方法回答“怎么测”，判定回答“多少算过”；判定值必须注明来源（法规 / 客户 / 内部）。
2. **等级型结果**（灰卡、起球、平整度）是 0.5 级步长的有序数据，用通过率、分布或 kappa 一致性评价，**不计算 Cpk**。连续型结果（强力、缩率、克重）在测量系统合格、过程稳定且数据足够后才计算 Cpk。
3. **调湿**：物理测试前按 ASTM D1776 标准大气（21℃、65% RH，公差按现行版本）平衡；试样状态与调湿时间写入报告。

## 二、 色牢度 (AATCC)

| 项目 | 方法 | 要点 | 常见参考值（非法定） |
| :--- | :--- | :--- | :--- |
| 摩擦 | AATCC 8（Crockmeter）；AATCC 116（旋转式，适用小面积/印花） | 9 N 垂直力，往复 10 次；湿摩摩擦布含水率须控制在 65 ± 5%（最敏感变量） | 干摩 ≥ 3.5–4；湿摩 ≥ 2.5–3（深色、牛仔常放宽） |
| 水洗 | AATCC 61（1A/2A/3A 等） | 2A：49℃、45 min、钢珠，约相当于 5 次家庭中温洗；3A：71℃ | 变色 ≥ 4；多纤维沾色 ≥ 3–3.5；撞色款常要求 ≥ 4 |
| 光照 | AATCC 16.3（氙弧） | 服装常用 20 AFU；窗帘、户外 40–80 AFU | ≥ 4（家用窗帘按客户曝光量） |
| 水渍 | AATCC 107 | 38℃、18 h、加压 | 变色 ≥ 4；沾色 ≥ 3–3.5 |
| 汗渍 | **AATCC 15（仅酸性汗液，pH 4.3）**；需碱性汗液时用 ISO 105-E04 | 38℃、6 h、加压 | 变色 ≥ 4；沾色 ≥ 3–3.5 |
| 氯水 | AATCC 162（泳池水）；AATCC 188（次氯酸钠漂白洗涤） | 泳装按客户有效氯浓度与循环次数 | 泳装常 ≥ 4 |
| 非氯漂 | AATCC 172 | 过氧化物类漂白剂 | 变色 ≥ 4 |
| 颜色评定 | **AATCC EP1 变色灰卡、EP2 沾色灰卡**；**EP9 目视色差评定**；**EP6 仪器测色**；ΔE CMC(2:1) 按 ASTM D2244/客户公式 | 缸差、批次配套、同色异谱用 EP9/EP6 与多光源评定，**不要用 EP1 评缸差** | Lab dip ΔE CMC ≤ 0.8–1.0；MI 由客户定义 |

## 三、 物理与机械性能 (ASTM)

| 项目 | 方法 | 适用范围 | 常见参考值（非法定） |
| :--- | :--- | :--- | :--- |
| 拉伸 | ASTM D5034（抓样）/ D5035（条样） | 梭织 | 轻薄 ≥ 25 lbf；常规 ≥ 40–50 lbf；工装 ≥ 80–100 lbf |
| 撕破 | ASTM D1424（Elmendorf）/ D2261（舌形） | 梭织 | 服装与床品常 ≥ 2.5–3.5 lbf；牛仔大身常远高于此值，破坏区另定 |
| 顶破 | ASTM D3786（液压）/ **D3787（钢球，针织常用）** | 针织 | 内衣 ≥ 40 psi 量级；卫衣 ≥ 50–75 psi；钢球法以 lbf 计 |
| 起球 | ASTM D3512（乱翻式）/ D4970（马丁代尔） | 全品类 | 洗前 ≥ 3.5；洗后 ≥ 3–3.5（抓绒、磨毛按客户放宽） |
| 梭织接缝 | **ASTM D1683**（梭织服装接缝失效：滑移、断线、面料断裂） | 服装梭织 | 按客户：如规定载荷下开口 ≤ 6 mm，或接缝强力 ≥ 15–25 lbf |
| 家具布接缝滑移 | **ASTM D4034** | 软体家具面料 | 按客户 |
| ~~ASTM D434~~ | **已于 2004 年撤销**，无直接替代 | — | 历史资料中出现时，应换算到 D1683 / D4034 / 客户方法 |
| 弹性接缝 | 客户接缝延伸/循环方法（规定伸长率、循环次数、夹距） | 针织高弹 | 按客户；D1683 不能直接用于判定针织弹性接缝 |
| 耐磨 | ASTM D4157（Wyzenbeek）/ D4966（Martindale） | 家具布、服装 | 一般商用 ≥ 15,000 double rubs；重度商用 ≥ 30,000 |
| 簇绒拔出 | **ASTM D1335** | 地毯 | 住宅地毯常见底线：割绒 ≥ 3.0 lbf，圈绒 ≥ 6.25 lbf（如 HUD 要求） |
| 按扣 | **ASTM D7142**（爪扣钉合牢度）；ASTM D4846（开合力） | 服装 | 童装常 ≥ 15 lbf 保持 10 s（零售商方法） |
| 拉链 | ASTM D2061 | 拉链 | 按号数与客户 |
| 盐雾 | ASTM B117 | 金属辅料 | 按客户小时数与锈蚀判定 |
| 逆反射 | ASTM E810；ANSI/ISEA 107（合同指定版本） | 高可视服装 | 按标准与等级 |
| 静水压 | AATCC 127 | 防水面料/接缝 | 按产品声明与客户（接缝试样制备按客户） |
| 防钻绒 | IDFB 防钻绒测试（转笼/摩擦法，按客户指定部分与版本）；EN 12132-1；FTMS 191A 5530（历史军标） | 羽绒制品 | 按客户计数规则，如 ≤ 10–15 根 |
| 吸水 | AATCC 79（滴水法）/ AATCC 198（水平芯吸） | 毛巾、功能面料 | 毛巾常 ≤ 3–5 s |

> **ASTM D4850 是纺织术语标准，不是防钻绒方法。**

## 五、 化学测试（多数为 RSL，非联邦法定）

| 物质 | 方法 | 依据 | 常见要求 |
| :--- | :--- | :--- | :--- |
| 甲醛 | AATCC 112（密封瓶释放法）/ ISO 14184-1（水萃取，与日本法 112 对应） | **无联邦纺织品甲醛限值**；零售商 RSL；Prop 65 警示 | 婴幼儿 ≤ 16–20 ppm、接触皮肤 ≤ 75 ppm（须写明方法：两种方法结果不可直接比较） |
| pH | AATCC 81 / ISO 3071 | 客户要求 | 4.0–7.5 或 5.5–7.5（按客户） |
| 偶氮芳香胺 | EN ISO 14362-1/-3 | 欧盟 REACH 附件 XVII 第 43 条 30 mg/kg；美国为零售商 RSL | RSL 常 ≤ 20 mg/kg |
| PFAS | 总有机氟（燃烧离子色谱）+ 目标物 LC-MS/MS | 加州 AB 1817 等州法 | TOF < 100 ppm（2027 年起 < 50 ppm，加州） |
| 铅 | CPSC-CH-E1001/E1002/E1003 | CPSIA（儿童产品） | 涂层 ≤ 90 ppm；基材 ≤ 100 ppm |
| 镉 | 经验证的消解/ICP 方法 | **无联邦服装镉限值**；华盛顿州等州儿童产品法、零售商 RSL；玩具按 ASTM F963 可溶镉 | RSL 常 ≤ 40–100 ppm（按客户） |
| 邻苯 | CPSC-CH-C1001-09.4 | 16 CFR 1307（玩具与儿童护理用品）；Prop 65；RSL | 各 ≤ 0.1% |
| 阻燃剂 | GC-MS / LC-MS | Prop 65、州法、RSL | 按客户禁用清单 |
| 异味 | 无统一美国标准：感官评定按客户训练嗅辨程序；ISO 17299 为**仪器法**（检测管/GC）测消臭性能 | 客户要求 | 按客户等级 |
