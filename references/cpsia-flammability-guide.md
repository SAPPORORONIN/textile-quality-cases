# CPSIA 与燃烧性法规快速参考指南

> **Quick Reference: CPSIA, Flammability & Key US Federal Textile Regulations**

> 本指南为工作参考，不构成法律意见。法规条目以 `registry/regulations.json` 为唯一事实来源；如有冲突，以注册表为准。

---

## 一、 CPSIA（Consumer Product Safety Improvement Act of 2008）

### 1.1 核心条款速查

| 条款 | 内容 | 适用范围 | 限值/要求 |
| :--- | :--- | :--- | :--- |
| **Sec. 101** | 儿童产品铅含量（基材） | 12 岁及以下儿童使用的产品 | **≤ 100 ppm**（基材铅） |
| **Sec. 101(f)** | 涂层铅含量 | 消费品涂层/表面涂料 | **≤ 90 ppm** |
| **Sec. 108** | 邻苯二甲酸酯 | **儿童玩具与儿童护理用品**（16 CFR 1307），不适用于普通童装 | DEHP, DBP, BBP, DINP, DIBP, DPENP, DHEXP, DCHP: 均 **≤ 1,000 ppm** |
| **Sec. 102** | 强制第三方测试 | 受 CPSC 消费品安全规则或禁令管辖的儿童产品 | 由 CPSC 认可实验室测试 |
| **Sec. 103** | 追溯标签 | 儿童产品 | 制造商/自有品牌名、产地、生产日期、批次号等可追溯信息的永久标签 |
| **Sec. 104(b)** | 耐用婴儿用品标准 | 婴儿床、高脚椅、游戏围栏等 | 须符合 ASTM/CPSC 强制标准 |

### 1.2 儿童产品证书（CPC）

所有进口或在美国生产的儿童产品（12 岁及以下）必须附有 CPC，内容包括：
1. 适用的 CPSC 消费品安全规则清单
2. CPSC 认可实验室的测试报告编号
3. 进口商/制造商/自有品牌的名称与联系方式
4. 测试时间与测试实验室信息
5. 产品标识信息（与追溯标签对应）

**注意**：CPC 是**制造商/进口商的声明**，不是实验室出具的证书。

### 1.3 追溯标签（Sec. 103）

儿童产品须有永久性标签（printed, stamped, stitched 等不可轻易移除的方式），包含足以追溯到制造商、生产批次、生产日期的信息。纺织服装常见做法：
- 在主标签或护理标签上印制批次号或日期代码
- 批次号编码规则需存档，以便追溯时解码

与 [SYS-012](case:SYS-012) 中 WMS 批次追溯联动：成品追溯标签上的批次号应与 WMS 入库批次号一致。

## 二、 燃烧性法规

### 2.1 16 CFR 1610 — 服装面料（General Wearing Apparel）

| 项目 | 内容 |
| :--- | :--- |
| **适用范围** | 成人与儿童服装面料（不含帽子、手套、鞋类） |
| **测试方法** | 45° 倾斜燃烧，1 秒引燃 |
| **分类** | Class 1（正常可燃性）— 合格；Class 2（中度可燃性）— 仅限起绒面料需标注警示；Class 3（快速剧烈燃烧）— **禁止** |
| **频率** | 首批面料必测；面料成分/结构变更后重测 |

大多数纺织面料为 Class 1，但轻薄起绒面料（如绒布、法兰绒、薄纱）可能达到 Class 3，需重点关注。

### 2.2 16 CFR 1615/1616 — 儿童睡衣

| 项目 | 内容 |
| :--- | :--- |
| **适用范围** | 儿童睡衣（1615: 0–6X 码；1616: 7–14 码） |
| **豁免** | 紧身合体（Tight-fitting）的 9 个月–14 岁睡衣在尺寸符合规定范围内可豁免燃烧测试 |
| **测试方法** | 垂直燃烧，3 秒引燃，测量 char length |
| **合格标准** | 5 个试样的平均 char length ≤ 7 英寸，且单个试样 **< 10 英寸**（10 英寸 = 全长炭化 = 不合格） |
| **洗涤后测试** | 洗涤 50 次后仍须合格 |
| **紧身合体豁免条件** | 不含易燃面料（如聚酯纤维起绒），尺寸必须在 CPSC 发布的紧身合体尺寸表范围内 |

### 2.3 16 CFR 1632 — 床垫与床垫垫

| 项目 | 内容 |
| :--- | :--- |
| **适用范围** | 床垫、床垫垫（mattress pad） |
| **测试方法** | 香烟引燃测试（Cigarette Ignition Test） |
| **合格标准** | 点烟后的炭化长度不超过 2 英寸 |

### 2.4 16 CFR 1633 — 床垫明火测试

| 项目 | 内容 |
| :--- | :--- |
| **适用范围** | 全尺寸床垫 |
| **测试方法** | 明火引燃（模拟床上用品着火） |
| **合格标准** | 峰值热释放率 ≤ 200 kW，30 分钟总热释放 ≤ 15 MJ |

## 三、 其他关键联邦法规速查

### 3.1 纤维成分标识（Textile Fiber Products Identification Act / 16 CFR 303）

- 所有纺织品必须标注纤维名称和百分比（按重量递减排列）
- 纤维含量允差 ±3%（16 CFR 303.43）
- 装饰纤维 ≤ 5% 可注明"exclusive of decoration"
- 弹性纤维（如 spandex）无论含量都必须标注

### 3.2 护理标签（Care Labeling Rule / 16 CFR 423）

- 服装必须有护理标签，标注至少一种合理的护理方法
- 标签方法须有 reasonable basis（可以是测试、技术文献或行业知识）——品牌对护理标签的准确性负责
- 可用符号（ASTM D5489）或文字，但仅用符号时可能需要额外说明

### 3.3 产地标识（Made in USA / FTC Enforcement Policy）

- "Made in USA"：产品的"全部或几乎全部"（all or virtually all）制造过程在美国完成
- 进口产品必须标注原产国（19 CFR 134 — 海关规定，非 FTC）
- "Assembled in USA from imported materials"等限定表述有具体的 FTC 合规要求

### 3.4 绳带安全（16 CFR 1120 — Drawstrings）

- **2T–12 码**儿童外衣上衣的帽子和颈部区域**禁止拉绳**
- **2T–16 码**儿童外衣下摆和底部拉绳不得超出服装底部
- 参考 ASTM F1816 标准
- [SYS-012](case:SYS-012) 的模拟演练场景即涉及拉绳风险

### 3.5 PFAS 限制（加州 AB 1817 — 州法规，非联邦）

- 2025 年 1 月 1 日起，加州禁止在纺织品中有意添加 PFAS
- 适用于服装、配饰、手提包、背包、窗帘、家具面料等
- 参考 [RM-008](case:RM-008) 的 C0 DWR 替代案例
