# 案例库章程与适用范围

## 1. 目的
本案例库为美国市场服装、家纺与原辅料质量管理提供**可复核的教学案例、工作模板与法规/标准参考**，服务三类用途：
1. 质量团队培训与新人上手；
2. 产前风险评审时快速检索同类失效模式；
3. 质量岗位面试准备（须遵守 [GOV-08 面试使用规范](doc:GOV-08)）。

## 2. 不是什么
- **不是法律意见**。法规条目是工作参考，正式判定以官方原文、客户手册与法务意见为准。
- **不是真实事件记录**。除非 `provenance` 标为 `anonymized-real` 并有证据存档，所有案例均为示例案例，数字为量级合理的教学数据。
- **不是客户标准**。案例中的“客户要求”是示例，实际验收以合同为准。

## 3. 设计原则
| 原则 | 具体做法 |
| :--- | :--- |
| **单一事实来源** | 标准、法规、指标口径、分类只在 `registry/` 维护一次；案例的数字只在 `case.json` 维护一次，叙述与卡片从中引用 |
| **规则可执行** | 治理规则尽量写成校验器规则（`npm run validate`），人工评审只处理机器判断不了的部分 |
| **区分三种要求** | 法定要求、客户/零售商要求、行业惯例必须分开写，不能混成“美标限值” |
| **损失与处置必写** | 每个质量事故案例都必须交代在库/在制品处置与损失口径，不写“完美挽救” |
| **证据优先** | 法规与标准条目注明来源和核实日期；未核实的标为 `verifiedAt: null`，而不是猜测 |
| **可追溯变更** | 内容有版本号、评审状态与变更日志 |

## 4. 范围
- **市场**：美国（联邦 + 主要州法）。其他市场需新增 `jurisdiction` 后再纳入。
- **品类**：服装、家纺、面料与辅料、供应链体系。
- **阶段**：产前/开发、产中、出货/到港、售后（定义见 `registry/taxonomy.json`）。

## 6. 成功标准
- 校验器零错误；警告数逐季下降；
- 法规注册表 100% 有负责人，`verifiedAt` 不超过 180 天；
- 案例从 `draft` 到 `approved` 的比例逐季提高；
- 培训与评审使用者反馈“能直接用于工作”的比例。
