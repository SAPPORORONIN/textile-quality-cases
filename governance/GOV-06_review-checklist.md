# 评审清单

评审前先运行 `npm run validate`，确认零错误；建议再运行一次独立审计 `/audit-cases <ID>`（见 [GOV-10](doc:GOV-10)），并处理其中的 Critical 与 Major 发现。下列条目中标 🤖 的由校验器自动检查，评审人只需确认；其余需要人工判断。

## A. 技术评审
- [ ] 失效机理在物理/化学上成立；没有“反射率随光源变化”这类错误
- [ ] 根因有**验证试验**支撑（对比试验、分层复测），不只是推理
- [ ] 方法选用正确，条件写清（洗涤次数、方向、光源、计数规则）🤖 方法存在且未撤销
- [ ] 措施能解决根因，并评估了副作用（如降温定形后复测缩率、加柔软剂后复测滑移）
- [ ] 时间线与工序周期匹配（重新纺纱/织造/整理需要数周）
- [ ] 已生产货物的处置合理：不可逆的损伤没有被写成“返工后合格” 🤖 事故类必须有处置
- [ ] 数字量级可信（与 [GOV-04](doc:GOV-04) 中的行业参考对照）

## B. 合规评审
- [ ] 法定要求、客户要求、行业惯例分得清 🤖 拦截“美标限值”等表述
- [ ] 引用的法规适用于该产品（儿童/成人、尺码段、产品类型、销售州）
- [ ] 引用的法规条目已核实且未过期 🤖 未核实或超过 180 天给警告
- [ ] 声明（成分、支数、产地、羽绒、低过敏、阻燃、再生、防水）都有依据，降级销售时同步修改声明
- [ ] 儿童产品：第三方测试、CPC、材料变更后重测、追溯标签
- [ ] 进口：UFLPA 溯源、CPSC 证书电子申报
- [ ] 没有点名真实企业作为事件主体 🤖 品牌名单

## C. 数字与口径
- [ ] 指标使用注册表定义 🤖 指标 ID 存在
- [ ] 指标前后值与叙述一致 🤖
- [ ] 损失台账加总正确，口径注明 🤖
- [ ] 退货率区分总退货与质量原因 🤖 指标 ID 区分
- [ ] Cpk 只用于允许的指标，且注明子组数与 MSA 🤖 等级型指标禁止 Cpk
- [ ] 小样本写出分子分母

## D. 一致性
- [ ] 同一事实在案例、模板、SOP、面试材料中只出现一个版本；其他文件用 `{{ID.path}}` 引用或链接 🤖 引用可解析
- [ ] STAR 不引入新数字，并写出代价
- [ ] 标题、分类、阶段与内容一致 🤖 枚举值合法

## 评审结论
按 `templates/review-record.md` 记录：通过 / 有条件通过（列出必改项）/ 退回。
