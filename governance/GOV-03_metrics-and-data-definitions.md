# 指标与数据口径

指标定义的唯一来源是 `registry/metrics.json`；本文解释规则与常见误用。新增指标先在注册表登记，再在案例中使用。

## 1. 退货类指标
| 指标 | 分子 | 分母 | 常见误用 |
| :--- | :--- | :--- | :--- |
| 总退货率 | 全部退货件数 | 售出件数 | 服装电商通常 15–30%，把 0.3% 这类数字写成总退货率是不可信的 |
| 质量原因退货率 | 经**实物复核**归因于质量缺陷的退货 | 售出件数 | 用客服自由文本或消费者勾选代替实物复核 |
| 供应商责任质量退货率 | 归因于该供应商制造缺陷的退货 | 该供应商发货件数 | 把尺码、页面、仓配原因算到工厂头上 |
| 尺码/颜色/适配等原因退货率 | 对应原因码退货 | 售出件数 | 写成“占总退货的 x%”后又当退货率比较 |

**规则**：质量 KPI 一律使用质量原因退货率；总退货率只作背景，并说明尺码、偏好、政策的影响。

## 2. FTR
- **稽核口径**：品牌 QA、第三方或飞行稽核的首次终检结果，按批次计。用于绩效与计分卡。
- **自检口径**：供应商 DQA 的自检结果，只作对照；两者差距用于管理 DQA，不作为业绩。

## 3. 质量成本
- **COPQ（追偿前）** = 内部故障成本 + 外部故障成本。
- **净损失** = COPQ − 已回收的供应商赔偿。
- 追偿是成本转移，不是供应链总成本下降：报告时“故障减少”和“追偿改进”分开列，并扣除新增的预防/鉴定投入；同时跟踪 FOB，防止供应商把索赔加价转回。
- **索赔回收率** = 已回收 / 已确认且到期的供应商责任索赔；同时报告争议中金额与账龄。

## 4. 损失台账（case.json → ledger）
- `basis` 必填：`FOB`、`实际成本`、`实际支出`、`净损失` 之一。
- 只计入确实发生的损失：已售出且未退回的产品不是损失；“货值”不等于“挽救的金额”。
- `items` 之和 = `totalUsd`（容差 1%）。

## 5. 过程能力
- Cpk 只用于连续型、过程稳定、测量系统合格（%GRR 一般 < 10%，10–30% 需说明）且子组数 ≥ 25 的数据。
- 均值在规格外时 Cpk 为负，必须如实报告。
- 等级型数据（灰卡、起球、平整度）不算 Cpk，报告通过率与等级分布；一致性用 Cohen's kappa。
- 破坏性测试样本少时，先按“每批全部合格 + 最小值”放行，累计足够数据后再评估能力。

## 6. 小样本与比率
- 样本量 < 30 时同时写分子分母（如 1/16）。
- 前后比较的样本不同（如 12 人与 16 人）时要说明，不得暗示统计显著。

## 7. 观察期
- 上市后改善至少观察一个完整销售周期（通常 8–12 周），并说明促销、渠道、品类结构是否可比。
