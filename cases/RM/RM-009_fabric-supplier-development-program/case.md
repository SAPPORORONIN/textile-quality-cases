## 一、 案例背景

- **企业背景**: 美国服装与家纺品牌，年面料采购量约 1,500 万米，分布在约 15 家面料供应商
- **现状**: 品牌对面料供应商的质量管理以"事后纠正"为主：
  1. 来料检验（IQC）发现问题 → 退货或 8D → 供应商口头承诺改善 → 下一批可能还出问题
  2. 品牌 QA 团队不了解面料厂的过程能力——不知道供应商的染色 Cpk 是多少，也不知道克重波动的主要来源
  3. 8D 根因分析经常停留在"操作员调错参数"或"原材料批次波动"，缺乏系统性的过程改善
- **触发事件**: 统计年度面料来料合格率，3 家采购量最大的战略面料厂（占采购量 60%）合格率分别为 79%、83%、84%，加权平均 **82%**。这意味着每 5 批面料就有近 1 批不合格，导致成衣工厂停线等料、紧急换料、交期延误
- **改进目标**: 对 3 家战略面料厂导入过程控制能力，将来料合格率提升至 93% 以上

---

## 二、 根因分析

### 2.1 面料不合格 Pareto（3 家战略厂）

| 不合格类型 | 占比 | 典型问题 |
| :--- | :--- | :--- |
| 色差（ΔE 超标） | 35% | 缸差大、与确认样偏差 |
| 克重偏差 | 25% | 偏轻或偏重超公差 |
| 缩水率超标 | 18% | 定型不充分、预缩不到位 |
| 外观疵点 | 15% | 四分制评分超标 |
| 其他 | 7% | 手感、pH、色牢度等 |

### 2.2 根因（深层）

| 表面问题 | 深层根因 |
| :--- | :--- |
| 色差大 | 染色车间无 SPC 监控，配方调整靠师傅经验，无打样与大货的系统化对色流程 |
| 克重偏差 | 织造和定型工序无在线监控，克重靠离线抽检（每班 2 次），发现偏差时已有大量不合格品 |
| 缩水率超标 | 预缩工艺参数（速度、温度、水分）未标准化，不同班次不同设定 |

核心问题：面料厂的质量管理停留在"出厂检验 → 合格放行 / 不合格返工"，没有过程控制能力。

## 三、 体系建设

### 3.1 供应商质量发展计划（SQD）框架

分 3 个阶段，每阶段约 3–4 个月：

| 阶段 | 目标 | 活动 |
| :--- | :--- | :--- |
| **Phase 1: 测量** | 建立过程能力基线 | MSA 验证测量系统 → 采集 ≥ 25 批数据 → 计算 Cpk |
| **Phase 2: 控制** | 导入 SPC 在线监控 | 建立控制图 → 培训操作员读图 → 失控响应流程 |
| **Phase 3: 改善** | 针对低 Cpk 指标做过程改善 | 根因分析 → DOE 优化参数 → 验证 → 标准化 |

### 3.2 Phase 1: 测量系统验证 + 基线

**MSA 验证（参考 [PB-MSA](doc:PB-MSA)）**：

| 指标 | MSA 方法 | 合格标准 |
| :--- | :--- | :--- |
| 克重 | 交叉 Gage R&R（3 操作员 × 10 样品 × 3 重复） | %Study Var ≤ 30%（勉强可用级；≤ 10% 为优秀，参考 [PB-MSA](doc:PB-MSA)） |
| 色差 ΔE | 仪器与目视比对 + 仪器间比对 | 仪器间 ΔE 偏差 ≤ 0.15 |
| 缩水率 | Gage R&R（3 操作员 × 10 样品 × 2 重复，嵌套设计因破坏性） | %Study Var ≤ 30%（勉强可用级） |

**过程能力基线**：

收集 25+ 批次的克重和色差数据，计算初始 Cpk：

| 面料厂 | 克重 Cpk | 色差 Cpk（以 ΔE ≤ 1.0 为规格） |
| :--- | :---: | :---: |
| 厂 A | 0.72 | 0.58 |
| 厂 B | 0.91 | 0.82 |
| 厂 C | 0.85 | 0.65 |

3 家厂的克重和色差 Cpk 均 < 1.0，说明过程能力不足——即使过程在"控制"中，仍然会持续产出不合格品。

### 3.3 Phase 2: SPC 导入

在每家面料厂部署：
- **克重 I-MR 控制图**: 每卷面料下机后取样称重，数据录入看板，超控制限即停机调查（参考 [PB-SPC](doc:PB-SPC)）
- **色差 Xbar-R 控制图**: 每缸染色后取 3 个位置测 ΔE，3 点一组绘图
- **失控响应 SOP**: 操作员发现失控点 → 停线 → 通知班长 → 调查原因 → 记录 → 恢复

**培训**: 品牌 QA 工程师到厂培训操作员和班长（每厂 2 天），重点是"看懂控制图"和"失控时怎么做"。

### 3.4 Phase 3: 过程改善

针对 Cpk < 1.0 的指标，做根因分析和改善：

**克重改善（厂 A 为例）**：
- 根因: 定型机速度和超喂率设定不一致（不同班次的师傅有不同习惯）
- 改善: 标准化定型参数（速度、温度、超喂率）→ 写入 SOP → 参数锁定（设备权限控制）→ 验证 3 批
- 结果: 克重 Cpk 从 0.72 → 1.35

**色差改善（厂 A 为例）**：
- 根因: 打样用 2 kg 染色锅，大货用 500 kg 溢流染色机，液比和升温曲线差异导致缸差
- 改善: 用 DOE 优化大货染色参数（液比、升温速率、保温时间），使大货色光逼近打样
- 结果: 色差 Cpk 从 0.58 → 1.12

## 四、 验证成效

SQD 计划全程约 10 个月（Phase 1: 3 个月，Phase 2: 3 个月，Phase 3: 4 个月）。完成后：

| 指标 | 改善前 | 改善后 | 目标 |
| :--- | :---: | :---: | :---: |
| 来料合格率（3 家战略厂加权） | **82%** | **95%** | 93% |
| 克重 Cpk（3 厂平均） | 0.83 | 1.28（厂 A: 1.35, 厂 B: 1.22, 厂 C: 1.26） | ≥ 1.00 |
| 色差 Cpk（3 厂平均） | 0.68 | 1.08（厂 A: 1.12, 厂 B: 1.05, 厂 C: 1.06） | ≥ 1.00 |
| 面料不合格导致的成衣停线事件 | 季均 8.5 次 | 季均 1.2 次 | — |

## 五、 面试 STAR 讲稿

> **面试官提问**: "你如何提升供应商的质量能力？"

- **Situation**: "我们 3 家战略面料厂占采购量 60%，但来料合格率只有 82%。面料问题导致成衣工厂频繁停线等料。供应商质量管理停留在'出了问题发 8D'的纠正模式。"
- **Task**: "我负责建立面料供应商质量发展计划（SQD），从纠正驱动转为能力提升。"
- **Action**:
  1. Phase 1: MSA 验证面料厂的测量系统，采集 25+ 批次数据建立 Cpk 基线——发现 3 家厂的克重和色差 Cpk 均 < 1.0；
  2. Phase 2: 在每家厂导入 SPC 控制图（克重 I-MR、色差 Xbar-R），培训操作员和班长，建立失控响应 SOP；
  3. Phase 3: 针对 Cpk < 1.0 的指标做根因分析和 DOE 优化——如标准化定型参数提升克重 Cpk，优化染色参数提升色差 Cpk。
- **Result**: "10 个月后来料合格率从 82% 升到 95%，克重 Cpk 从 0.83 升到 1.28，色差 Cpk 从 0.68 升到 1.08。停线事件从季均 8.5 次降到 1.2 次。投入包括：品牌 QA 工程师驻厂培训（每厂 2 天 × 3 阶段）、协助厂端部署控制图看板和校准量具。关键是不只告诉供应商'你不合格'，而是帮他们建立过程控制能力。"
