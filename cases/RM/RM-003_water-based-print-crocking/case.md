## 一、背景与失效表现

环保水性胶浆印花在首批黑色卫衣（订单 49,000 件，货值 $980K）上出现湿摩擦掉色、图案边缘龟裂和洗后局部脱落，在出货前测试中被发现。AATCC 8 湿摩擦为 **1.5 级**（客户对印花要求 ≥ 3.0 级）；按客户规定的成衣家庭洗涤程序（AATCC 150 条件）洗 5 次后，印花面积损失约 **18%**。部分样品还出现残余气味，需要按客户 RSL 进行针对性筛查。

## 二、遏制与调查

- 冻结同一胶浆批次和印花车间半成品，按颜色、网版目数和烘焙设备分层。
- 测量胶浆固含、黏度、柔软助剂比例、印花厚度、烘焙实测温度和织物含湿率。
- 对图案中心、边缘、叠印区分别测试，区分附着力不足与柔韧性不足。

**测量结果**：已印的 9,000 件用了 3 个浆料批，印花批与浆料批按调浆记录一一对应。

| 项目 | 浆料批 A、B（对应 5,600 件） | 浆料批 C（对应 3,400 件） | 胶浆厂规格 / 推荐 |
| :--- | :---: | :---: | :---: |
| 固含 | 38–39% | 32% | 40 ± 2% |
| 柔软/增塑助剂（占胶浆） | 4% | 9%（印花厂为改善手感自行追加） | ≤ 5% |
| 图案表面实测温度 / 停留（测温纸 + 表面热电偶） | 128–135℃ / 60–70 s | 128–135℃ / 60–70 s | ≥ 150℃ / ≥ 2 min |
| 叠印区闪干后残余水分（称重法） | 6–8% | 6–8% | ≤ 2% |

- 烘焙设备显示 150℃，实际图案表面只有 128–135℃，两类浆料批都烘焙不足；浆料批 C 另外固含低、助剂超量。
- **对照试验**（同一卫衣布，每组 5 件，湿摩 / 洗 5 次后印花面积损失）：浆料批 A 按大货烘焙 1.5 级 / 17%，按图案表面 150℃、2.5 min 充分固化 3.5 级 / 无脱落；浆料批 C 按大货烘焙 1.5 级 / 19%，充分固化后仍只有 2.0 级 / 12%。结论：A、B 批的问题是固化不足，可以靠后固化补救；C 批即使充分固化也不合格，问题在浆料本身。

## 三、根因分析

1. **烘焙不足（全部批次）**：设备显示 150℃，图案表面实测 128–135℃、停留 60–70 s，低于胶浆厂要求；
2. **叠印层间残留水分**（6–8%），洗后形成微孔和界面剥离；
3. **浆料批 C 固含偏低**（32%），有效成膜厚度不足；
4. **浆料批 C 柔软/增塑助剂超量**（9%）：印花厂为追求柔软手感自行追加，降低了成膜强度，并迁移到表面，造成湿摩擦掉色。

## 四、纠正措施与验证

- 重新定义胶浆固含、黏度、刮胶压力和网版目数的工艺窗口，减少不必要的厚涂。
- 用数据记录器确认图案表面实际温度和停留时间，建立换色后的首件烘焙确认。
- 采用分段烘干和适度后固化，确保叠印层间水分释放；对高伸长图案增加弯折与拉伸后检查。
- 柔软助剂按胶浆厂推荐上限使用，并做客户 RSL 筛查（含邻苯类等）。代表性样品湿摩提升至 **4.0 级**，按同一洗涤程序洗 5 次后无可见脱落，图案裂纹在客户外观等级内。
- **已印 9,000 件的化学筛查**：因为有残余气味，且浆料批 C 助剂超量，按浆料批取样送第三方实验室：
  - 助剂成分：GC-MS 鉴定为非邻苯类增塑剂（对苯二甲酸酯类）；邻苯二甲酸酯按客户 RSL 清单筛查，均低于报告限 50 ppm；
  - 甲醛（ISO 14184-1）：后固化前 35–48 ppm，后固化后 ≤ 20 ppm；APEO 未检出；
  - 气味：来自欠固化胶浆中残留的氨（中和剂）和水分，后固化后按客户感官程序复评，合格；
  - **Prop 65**：本款在加州销售。合规人员按客户 Prop 65 程序评估：未检出清单中的邻苯二甲酸酯，甲醛在后固化后低于客户 RSL 限值，估算暴露低于安全港水平，不需要加警示；结论、报告编号与评估记录归档。若复测发现清单物质暴露超过安全港，须按规定格式加警示或不在加州销售。
- **库存处置**：已印花的 9,000 件按浆料批区分（依据调浆记录与上面的对照试验）：
  - 浆料批 A、B 的 5,600 件：问题是烘焙不足，在隧道烘箱中后固化，**图案表面实测 150℃**（测温纸与表面热电偶，不以设备设定值为准）、停留 2.5 min。每个印花批抽 5 件，湿摩达到 3.5 级、洗 5 次后无脱落，甲醛与气味复测合格，放行；
  - 浆料批 C 的 3,400 件：成膜物不足、增塑剂超量，后固化既补不回成膜物，也去不掉增塑剂（对照试验中充分固化后仍只有 2.0 级），无法补救，降级销售。
- **降级品的标签与渠道**：
  - 印花图案本身带品牌标识，去掉标签也去不掉，因此不进第三方清仓渠道，只在品牌自有奥特莱斯渠道销售；
  - 纤维成分、原产国、企业识别（RN）等法定标签全部保留；
  - 原护理标签按原程序机洗 5 次会损失约 18% 的印花面积，没有合理依据（16 CFR 423）。用留样按“冷水手洗、反面洗、晾干”洗 5 次，印花面积损失约 2%、无新增裂纹，据此逐件加缝新的永久护理标签，吊牌注明“印花耐洗性低于正价品”。
- **剩余约 40,000 件与补产**：订单 49,000 件中剩余约 40,000 件尚未印花，暂停印花；新工艺首件（固含、图案表面实测温度、闪干后残余水分）经 QA 放行后恢复，每个印花批按新放行条件测试。降级的 3,400 件由成衣厂补裁补印，面料厂补 3,400 件用量的面料约 2 周。
- **时间线**：第 1 周冻结并完成测量；第 2 周完成对照试验，按浆料批区分；第 2–3 周确认新工艺窗口并做首件验证（洗 5 次约 3 天）；第 3 周对 5,600 件后固化并复测；第 4 周恢复印花剩余 40,000 件；补产的 3,400 件随最后一批出运，最后一批比原计划晚约 3 周。
- **损失**：约 $52,300（实际成本）：3,400 件降级按 FOB $20 计 $68,000，奥特莱斯渠道回收约 40%，净损失 $40,800；5,600 件后固化实际支出 $7,000（约 $1.25/件）；化学筛查与复测 $4,500。印花厂是成衣厂的分包方，依据分包合同质量条款：印花不合格造成成衣降级或报废时，印花厂按成衣 FOB 扣除残值后的损失赔付，并承担返工与测试费用。

## 五、防再发

1. 印花放行必须同时包含干摩、湿摩、洗后外观和伸长后龟裂检查；
2. 烘焙曲线以图案实际温度为准，设备设定值不能替代验证；
3. 胶浆供应商变更、配方调整或环保声明变化时重新做 RSL 与耐久验证。

## 六、STAR 讲稿

- **Situation**：水性胶浆印花湿摩擦掉色，洗后还出现龟裂脱落。
- **Task**：兼顾环保要求、柔软手感和图案耐久。
- **Action**：重建胶浆固含、烘焙实温和叠印干燥窗口，补充分层耐久测试。
- **Result**：湿摩由 1.5 级提升至 4.0 级，洗 5 次后无可见脱落，图案裂纹在客户外观等级内。代价是 3,400 件降级、约 5.2 万美元损失（由印花厂承担），最后一批晚约 3 周出运。
