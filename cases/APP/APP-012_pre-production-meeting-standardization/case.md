## 一、 案例背景

- **企业背景**: 美国服装品牌，年采购约 600 万件，约 35 家成衣供应商
- **现状**: 品牌要求每个 PO 量产前召开产前会（Pre-Production Meeting / PP Meeting），但实际执行中：
  1. **议程不标准**: 有的工厂只讨论交期，有的只看面料确认样，没有统一的检查清单
  2. **关键角色缺席**: 工厂的裁剪主管、印花/绣花车间主管经常不参加，导致特殊工艺的风险点无人提出
  3. **无行动追踪**: 产前会发现的问题记在笔记本上，没有系统跟踪是否关闭——两周后量产开始时，有些问题依然没解决
  4. **QCP 不联动**: 产前会和质量控制计划（QCP）是两个独立的事，产前会发现的高风险点不会自动写入 QCP 加强检验
- **触发事件**: 一季内连续 3 个 PO 因"产前就已知但未处理"的问题拒批——含粘合衬配伍问题（类似 [RM-005](case:RM-005)）、印花对位误差、拉链色差。事后复盘发现这些问题在产前阶段已有信号，但没有被系统拦截
- **改进目标**: 标准化产前会流程，使其成为风险拦截的关键门禁

---

## 二、 根因分析（鱼骨图）

| 维度 | 根因 |
| :--- | :--- |
| **人（Man）** | QA 驻厂人员级别不够（初级 QC），无法主导风险讨论；工厂关键岗位缺席 |
| **法（Method）** | 无标准化议程和检查清单；产前会结论无跟踪系统 |
| **料（Material）** | 面辅料确认与产前会脱节——面料确认在 PD 端完成，QA 在产前会才第一次看到面辅料实物 |
| **机（Machine）** | QCP 和产前会是两个独立流程，不联动 |
| **环（Environment）** | 工厂视产前会为"品牌走形式"，配合度低 |

## 三、 体系建设

### 3.1 产前会标准化 SOP

**必须参加角色**（工厂端）：
- 工厂品质经理（主持）
- 生产计划主管
- 裁剪车间主管
- 缝制车间主管
- 特殊工艺车间主管（印花 / 绣花 / 水洗 / 粘合，视产品而定）

**品牌端**：QA 工程师（不是初级 QC）

### 3.2 标准化议程（必检清单）

| 议程项 | 检查内容 | 红旗规则（任一触发 → 暂缓开裁） |
| :--- | :--- | :--- |
| **面料确认** | 大货面料与确认样对比（色差、手感、克重） | ΔE (CMC 2:1, D65/10°) > 1.0 或克重偏差 > 5% |
| **辅料确认** | 拉链、纽扣、粘合衬、弹力带等实物核对 | 任一辅料未到齐或与确认样不符 |
| **面辅料配伍** | 粘合衬与面料的压烫试验结果、拉链与面料的色差 | 剥离强力 < 最低值或缩水率差异 > 2% |
| **尺寸与版型** | Tech Pack 最新版确认、放码表核对、产前样试穿 | 产前样关键尺寸偏差 > 1 cm |
| **特殊工艺** | 印花 / 绣花 / 水洗的工艺参数和试产样确认 | 无试产样或试产样未获批准 |
| **法规合规** | 标签内容、测试计划、CPC（儿童产品）确认 | 测试未完成或标签内容有误 |
| **包装** | 折叠方式、吊牌位置、箱唛规格 | 未确认 |
| **交期与产能** | 排产计划、面料到料时间、产能瓶颈 | 面料未到齐但计划开裁 |
| **历史教训** | 查案例库：同工厂 / 同品类 / 同面料的历史质量问题 | 同类问题的纠正措施未验证 |

### 3.3 红旗暂缓机制

任一"红旗规则"触发时，产前会结论为**暂缓开裁**：
- QA 工程师有权签发暂缓指令，无需请示总监
- 暂缓原因和预期解决时间记录在系统中
- 解决后复核通过方可开裁

### 3.4 行动追踪

产前会产生的行动项（Action Items）录入质量管理系统：
- 每条行动项有**责任人、完成日期**
- 开裁前所有行动项必须关闭——系统在开裁日前 3 天自动提醒未关闭项
- 未关闭 → 自动触发暂缓

### 3.5 QCP 联动

产前会的风险发现直接写入该 PO 的 QCP：
- 高风险工艺点 → QCP 中对应检验点加严（从抽检改为全检，或增加检验频次）
- 面辅料配伍风险 → QCP 中增加首件确认点
- 历史教训 → QCP 中增加针对性检验项

## 四、 验证成效

标准化产前会实施 2 个季度后：

| 指标 | 改善前 | 改善后 |
| :--- | :---: | :---: |
| FTR（全品类） | **87.5%** | **94.2%** |
| 产前阶段拦截率（产前发现的问题占量产前全部问题的比例） | 22% | 68% |
| "产前已知但未处理"导致的拒批 | 季均 3.2 次 | 季均 0.4 次 |
| 产前会召开率 | 75% | 98% |
| 行动项按时关闭率 | 无数据 | 91% |

**说明**: 产前会标准化带来的最大价值不是"发现更多问题"，而是"让已发现的问题在量产前被解决"。行动追踪和红旗暂缓机制是关键——没有追踪的产前会只是一场汇报。

## 五、 面试 STAR 讲稿

> **面试官提问**: "你如何确保产前环节的质量把控？"

- **Situation**: "一季内连续 3 个 PO 因'产前就已知但未处理'的问题拒批。复盘发现产前会流于形式——没有标准议程，关键角色缺席，发现的问题没有追踪系统。"
- **Task**: "我负责将产前会从走形式改造为风险拦截的关键门禁。"
- **Action**:
  1. 制定标准化产前会 SOP：9 项必检清单 + 红旗暂缓规则（任一红旗触发即暂缓开裁，QA 有权签发）；
  2. 规定工厂端必须参加的角色（品质经理、裁剪/缝制/特殊工艺主管），品牌端升级为 QA 工程师主导；
  3. 行动项录入系统追踪，开裁前 3 天自动提醒未关闭项；
  4. 产前会风险发现直接写入 QCP，高风险点对应加严检验。
- **Result**: "产前拦截率从 22% 提升到 68%，FTR 从 87.5% 升到 94.2%。投入包括：SOP 编制、质量系统开发行动追踪模块、35 家工厂推广培训。最关键的变化是'产前已知但未处理'导致的拒批从季均 3.2 次降到 0.4 次。"
