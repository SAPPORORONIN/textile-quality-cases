# 供应商质量管理架构

> **Supplier Quality Management Architecture for Textile & Apparel**

---

## 一、 架构概述

供应商质量管理不是单一活动（审厂或验货），而是一个覆盖供应商全生命周期的体系。本架构将供应商质量管理分解为**五个阶段**和**六个支撑能力**，每个阶段有明确的输入、活动、输出和决策点。

---

## 二、 供应商全生命周期五阶段

### 2.1 阶段概览

```
┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐
│  寻源    │──>│  准入    │──>│  监控    │──>│  发展    │──>│  退出    │
│ Sourcing │   │Onboarding│   │Monitoring│   │Development│  │  Exit    │
└──────────┘   └──────────┘   └──────────┘   └──────────┘   └──────────┘
```

### 2.2 各阶段详解

#### 阶段 1: 寻源（Sourcing）

| 项目 | 内容 |
| :--- | :--- |
| **目标** | 识别有潜力的供应商候选，初步评估匹配度 |
| **输入** | 品类需求、产能要求、合规要求、地理偏好 |
| **活动** | 供应商数据库搜索、行业展会、同行推荐、桌面调研（营业执照、认证、客户清单） |
| **输出** | 候选供应商短名单 + 桌面评估报告 |
| **决策** | 进入准入流程 / 不进入 |

#### 阶段 2: 准入（Onboarding）

参考 [SYS-010](case:SYS-010) 的四阶段准入流程。

| 子阶段 | 活动 | 关键判定 |
| :--- | :--- | :--- |
| **桌面审核** | 资质验证、合规文件审查、自评问卷 | 基本资质是否齐全 |
| **现场审厂** | 质量体系、产能、合规（社会责任、环保） | 审厂评分 ≥ 门槛 |
| **试单** | 小批量试产 + 全项测试 + DQA 终检 | FTR 达标 + 测试全部合格 |
| **正式认证** | 签署质量协议、纳入 ERP 供应商主数据 | Mentor 制过渡（首 2 季） |

**首 3 批来料 100% 检验 + 全项测试**（参考 [SOP-IQC](doc:SOP-IQC)）。

#### 阶段 3: 监控（Monitoring）

| 监控维度 | 数据来源 | 频率 | 案例参考 |
| :--- | :--- | :--- | :--- |
| 质量绩效 | FTR、AQL 检验结果、退货率 | 逐批 + 月度汇总 | [SYS-009](case:SYS-009) |
| 交期绩效 | OTD（On-Time Delivery）率 | 逐单 + 月度汇总 | — |
| 合规状态 | 测试合格率、认证有效期 | 逐批 + 年度审厂 | [REF-CPSIA](doc:REF-CPSIA) |
| 8D 表现 | 关闭周期、重复问题率 | 逐案 + 季度评审 | [SYS-011](case:SYS-011) |
| 合作配合度 | 响应速度、信息透明度 | 主观评分 + 季度 | — |

#### 阶段 4: 发展（Development）

| 发展模式 | 适用场景 | 活动 |
| :--- | :--- | :--- |
| **纠正驱动** | 质量问题频发 | 8D 根因分析 → 联合改善计划 → 驻厂辅导 |
| **能力提升** | 战略供应商、质量瓶颈 | SPC 培训、FMEA 导入、实验室能力建设 |
| **创新合作** | 新品类、新面料、新工艺 | 联合开发、试产验证、技术交流 |

#### 阶段 5: 退出（Exit）

| 触发条件 | 决策层级 | 退出流程 |
| :--- | :--- | :--- |
| 连续质量问题 + 改善无效 | QA 总监 + 采购 VP | 减单 → 暂停新单 → 在制订单完结后终止 |
| 严重合规违规 | VP 级 | 立即暂停 + 在制订单转移 |
| 业务调整 | 采购 VP | 提前通知 + 有序转移 |

退出不是惩罚——未能按时退出不合格供应商才是质量风险。

## 三、 六个支撑能力

### 3.1 供应商记分卡（Scorecard）

参考 [SYS-003](case:SYS-003)。

| 维度 | 权重建议 | 数据来源 |
| :--- | :--- | :--- |
| 质量（FTR、退货率、8D） | 40% | 检验系统、质量管理系统 |
| 交期（OTD） | 25% | ERP |
| 合规（测试合格率、审厂评分） | 20% | 测试报告、审厂报告 |
| 合作配合度 | 15% | QA/采购主观评分 |

评分频率：月度自动计算 + 季度人工校准。

### 3.2 风险分级（Risk Tiering）

参考 [SYS-009](case:SYS-009)。

| 等级 | 定义 | 对应的检验/监控强度 |
| :--- | :--- | :--- |
| **Tier 1 — 优选** | 记分卡 ≥ 90 分 + 连续 4 季度 | 跳批检验 + 年度审厂 |
| **Tier 2 — 合格** | 记分卡 70–89 分 | 正常检验 + 半年审厂 |
| **Tier 3 — 观察** | 记分卡 50–69 分 | 加严检验 + 季度审厂 + 改善计划 |
| **Tier 4 — 待退出** | 记分卡 < 50 分或严重违规 | 全检 + 月度审厂 + 退出评估 |

### 3.3 质量协议（Quality Agreement）

供应商准入时签署的质量协议应包含：
- AQL 标准与切换规则
- 测试要求与测试方法引用
- 8D 响应时限（参考 [SYS-011](case:SYS-011) SLA）
- 索赔条款
- 追溯要求（批次号、装箱单规范）
- 变更通知义务（面辅料、工艺、设备的变更须提前通知）

[RM-005](case:RM-005) 的粘合衬脱层案例正是因为供应商未通知胶网变更。

### 3.4 审厂体系

| 审厂类型 | 频率 | 重点 |
| :--- | :--- | :--- |
| 准入审厂 | 一次性 | 全面：质量体系、产能、合规、环保 |
| 年度复审 | 每年 | 质量体系维持 + 改善验证 |
| 专项审厂 | 事件触发 | 针对具体问题深入审查 |
| 飞行检查 | 不定期 | 不预通知，验证日常执行情况 |

### 3.5 沟通机制

| 沟通类型 | 频率 | 参与者 |
| :--- | :--- | :--- |
| 日常质量沟通 | 逐批/逐单 | QA 工程师 ↔ 工厂 QC |
| 月度质量回顾 | 每月 | QA 经理 ↔ 工厂质量经理 |
| 季度业务评审 | 每季 | QA 总监 + 采购 ↔ 工厂高管 |
| 年度战略对话 | 每年 | VP 级 ↔ 工厂 GM |

### 3.6 知识与标准共享

- 将品牌的质量标准、检验标准、常见缺陷图谱分享给供应商
- 提供关键工艺的最佳实践（如粘合衬压烫参数、拉链安装要求）
- 分享案例库中匿名化的失败案例作为培训材料
- 定期组织供应商质量峰会（年度）
