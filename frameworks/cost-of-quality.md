# 质量成本（COQ）框架

> **Cost of Quality Framework for Textile & Apparel Supply Chain**

---

## 一、 什么是质量成本

质量成本（Cost of Quality）不是"质量好的成本"，而是"因为质量问题而产生的全部成本 + 为预防质量问题而投入的全部成本"。它回答一个核心问题：**质量问题每年到底花了公司多少钱？**

在纺织服装行业，质量成本往往隐藏在各部门的预算中——退货计入销售、返工计入生产、空运计入物流——没有人知道总数，也就无法做出有优先级的改善决策。

## 二、 COQ 四分类

### 2.1 预防成本（Prevention Cost）

**花钱防止缺陷发生**——这是最值得投入的类别。

| 成本项 | 纺织服装中的体现 | 案例参考 |
| :--- | :--- | :--- |
| 供应商审厂与准入 | 审厂差旅、审计人员工资 | [SYS-010](case:SYS-010) |
| QA 培训 | 测试员培训、灰卡评级校准 | [PB-MSA](doc:PB-MSA) |
| FMEA / DFQ | 设计评审、面辅料可行性验证 | [PB-FMEA](doc:PB-FMEA)、[SOP-DFQ](doc:SOP-DFQ) |
| 质量管理系统 | 软件、数据库、仪表盘 | — |
| SPC 过程监控 | 控制图维护、数据采集 | [PB-SPC](doc:PB-SPC) |
| 产前会 / 大货确认 | 产前样确认、首件检查 | — |
| 法规合规前置 | 测试计划制定、法规追踪 | [REF-CPSIA](doc:REF-CPSIA) |

### 2.2 鉴定成本（Appraisal Cost）

**花钱发现缺陷**——检验和测试的直接成本。

| 成本项 | 纺织服装中的体现 | 案例参考 |
| :--- | :--- | :--- |
| 来料检验（IQC） | 验布人员、四分制检验工时 | [SOP-IQC](doc:SOP-IQC) |
| 成品终检（DQA） | QC 人员工资、差旅 | [SYS-009](case:SYS-009) |
| 实验室测试 | 第三方实验室测试费 | — |
| 仪器校准 | 拉力机、色差仪校准 | [PB-MSA](doc:PB-MSA) |
| 样品确认 | 面料确认样、色样、产前样 | — |

### 2.3 内部失败成本（Internal Failure Cost）

**出货前发现的缺陷造成的损失**。

| 成本项 | 纺织服装中的体现 | 案例参考 |
| :--- | :--- | :--- |
| 返工 | 拆线重缝、更换辅料 | — |
| 报废 | 无法返工的不合格品 | — |
| 降等处理 | 一等品降为二等品折价出售 | — |
| 停线等待 | 面料不合格导致缝制线停工等料 | [RM-005](case:RM-005) |
| 加急采购 | 替代面料加急采购的溢价 | — |
| 终检拒批 | 拒批后的返工/重检成本 | — |
| 延误罚款 | 因质量问题延误交期的罚款 | — |

### 2.4 外部失败成本（External Failure Cost）

**出货后发现的缺陷造成的损失**——这是最昂贵的类别。

| 成本项 | 纺织服装中的体现 | 案例参考 |
| :--- | :--- | :--- |
| 消费者退货 | 退货处理 + 退款 + 逆向物流 | — |
| 零售商扣款 | Chargeback / Deduction | [SYS-011](case:SYS-011) |
| 客户索赔 | B2B 客户的质量索赔 | [SYS-011](case:SYS-011) |
| 召回 | 产品召回的全部费用 | [SYS-012](case:SYS-012) |
| 空运 | 因质量问题补货的空运费（替代海运） | [APP-001](case:APP-001) |
| 品牌声誉损失 | 难以量化但影响最大 | — |
| 法律/罚款 | CPSC 罚款、消费者诉讼 | — |

## 三、 COQ 的经济学逻辑

### 3.1 冰山效应

可见的质量成本（测试费、返工费、退货）只是冰山一角。隐性成本包括：
- 因质量问题导致的订单丢失（客户不再下单）
- 供应商管理的额外精力（反复跟进同一个问题）
- 品牌价值侵蚀（消费者差评、社交媒体负面口碑）
- 团队士气下降（反复救火而非创造价值）

### 3.2 投入转移效应

成熟的质量管理体系中，**预防成本增加 → 失败成本大幅下降 → 总 COQ 下降**。

典型的 COQ 构成变化：

| 阶段 | 预防 | 鉴定 | 内部失败 | 外部失败 | 总 COQ 占收入比 |
| :--- | :---: | :---: | :---: | :---: | :---: |
| Level 1（反应式） | 2% | 15% | 25% | 58% | 高（15–25%） |
| Level 3（已定义） | 15% | 30% | 35% | 20% | 中（8–12%） |
| Level 5（优化） | 35% | 30% | 25% | 10% | 低（3–6%） |

**注意**：以上比例为概念性示意，企业应基于自身数据建立基线。

### 3.3 ROI 论证

向管理层论证质量投入时，用 COQ 框架：
- "我们每年因质量问题的外部失败成本是 $X"
- "其中 $Y 可以通过 Z 预防措施避免"
- "Z 措施的投入是 $W，投资回报 = (Y – W) / W"

## 四、 COQ 数据收集实操

### 4.1 数据来源映射

| COQ 类别 | 数据来源 | 部门 |
| :--- | :--- | :--- |
| 预防成本 | QA 部门预算、培训费用、审厂差旅、软件许可 | QA / 财务 |
| 鉴定成本 | QC 人员工资、第三方测试发票、仪器维护费 | QA / 财务 |
| 内部失败成本 | 返工记录（工厂）、报废记录、延误罚款 | 生产 / 采购 / 财务 |
| 外部失败成本 | 退货报告、零售商扣款、索赔记录、空运发票 | 销售 / 财务 / 物流 |

### 4.2 从小处开始

不要试图一开始就收集全部 COQ 数据——先从最容易获取且金额最大的类别开始：
1. **退货/退款金额**（电商后台直接可查）
2. **零售商质量扣款**（财务已有记录）
3. **第三方检测费**（QA 已有发票）
4. **空运补货运费**（物流已有数据）

这四项通常占外部失败 + 鉴定成本的 80% 以上，足以构建一个有说服力的 COQ 基线。

### 4.3 报告频率

| 报告 | 频率 | 受众 |
| :--- | :--- | :--- |
| COQ 仪表盘 | 月度 | QA 经理 |
| COQ 趋势报告 | 季度 | QA 总监 + 采购 VP |
| COQ 年度总结 | 年度 | C-Suite / 董事会 |

## 五、 COQ 与案例库的联动

案例库中每个 incident 类案例的 `ledger` 字段记录了该事件的直接损失。将案例库的损失数据汇总，就是外部失败成本的一部分：

| 案例 | 损失金额 | COQ 类别 |
| :--- | :--- | :--- |
| [APP-001](case:APP-001) | 按 case.json ledger | 外部失败（返工 + 空运） |
| [RM-005](case:RM-005) | $76,520 | 内部/外部失败（退货 + 返工） |
| [RM-006](case:RM-006) | $124,500 | 内部失败（面料报废/降等） |
| [SYS-011](case:SYS-011) | 索赔回收率提升 | 外部失败成本的回收 |

将质量改善项目的投入与 COQ 下降挂钩，是最有力的投资论证方式。
