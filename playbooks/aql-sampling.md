# 纺织服装 AQL 抽检方案设计手册

> **AQL Sampling Plan Design Guide per ANSI/ASQ Z1.4 for Apparel & Home Textile**

---

## 一、 AQL 基本概念

**AQL（Acceptable Quality Limit / 接收质量限）** 不是"允许的不良率"，而是在连续批次抽检中，被认为过程平均质量可接受的**最差质量水平**。一个 AQL = 2.5 的方案意味着：如果过程的真实不良率持续在 2.5% 左右，大约 95% 的批次会被接收。

关键理解：
- AQL 保护的是**消费者风险与生产者风险的平衡**，不是"2.5% 的货不合格也没关系"
- 单批接收不代表该批没有不良品——抽检是概率决策
- AQL 越小（如 1.0），抽样量越大，检出力越强，但成本越高

## 二、 ANSI/ASQ Z1.4 方案速查

### 2.1 检验水平（Inspection Level）

| 水平 | 样本量相对于 Normal/II | 适用场景 |
| :--- | :---: | :--- |
| S-1 至 S-4 | 更小 | 破坏性测试（如撕破、燃烧）——试样数量有限 |
| I（减少型） | 约为 II 的 40% | 低风险产品，历史质量稳定 |
| **II（正常型）** | **基准** | **默认选择** |
| III（加强型） | 约为 II 的 160% | 高价值/高风险产品 |

大多数品牌默认使用 **Normal/Level II**。

### 2.2 常用 AQL 与样本量（Normal/II 节选）

| 批量 | 样本量代码 | 样本量(n) | AQL 1.0 Ac/Re | AQL 2.5 Ac/Re | AQL 4.0 Ac/Re |
| :--- | :---: | :---: | :---: | :---: | :---: |
| 2–8 | A | 2 | 0/1 | 0/1 | 0/1 |
| 151–280 | G | 32 | 0/1 | 1/2 | 2/3 |
| 501–1200 | J | 80 | 2/3 | 5/6 | 7/8 |
| 1201–3200 | K | 125 | 3/4 | 7/8 | 10/11 |
| 3201–10000 | L | 200 | 5/6 | 10/11 | 14/15 |
| 10001–35000 | M | 315 | 7/8 | 14/15 | 21/22 |

Ac = 接收数，Re = 拒收数。批量中合格品与不合格品的比例决定接收概率。

### 2.3 缺陷分类与 AQL 对应

| 缺陷等级 | 定义 | 典型 AQL |
| :--- | :--- | :---: |
| **Critical** | 安全/法规违规（断针、铅超标、拉绳违规、燃烧不合格） | **0**（零接收） |
| **Major** | 影响产品功能或外观的主要缺陷（接缝开裂、严重色差、印花剥离、尺寸超差） | **2.5** |
| **Minor** | 轻微外观瑕疵（线头、轻微皱褶、内部标签偏移） | **4.0** |

## 三、 切换规则（Switching Rules）

Z1.4 的切换规则是风险分级动态抽检的基础，详见 [SYS-009](case:SYS-009)。

```
Normal → Tightened: 连续 5 批中 2 批拒收
Tightened → Normal: 连续 5 批合格
Tightened → 暂停: 累计 5 批仍处于 Tightened（未能恢复 Normal）→ 暂停接单
Normal → Reduced: 连续 10 批合格 + 生产稳定 + 批准
Reduced → Normal: 1 批拒收、或生产不稳定、或其他条件
```

**注意**：很多企业只用 Normal 方案而从不切换，这等于放弃了 Z1.4 最有价值的风险调节机制。[SYS-009](case:SYS-009) 展示了如何在实践中实施动态切换。

## 四、 面料检验：四分制与 AQL 的区别

成品用计数型 AQL（合格/不合格），面料用四分制（ASTM D5430）按疵点扣分：

| 疵点长度 | 扣分 |
| :--- | :---: |
| ≤ 3 in | 1 |
| 3–6 in | 2 |
| 6–9 in | 3 |
| > 9 in | 4 |
| 破洞 ≤ 1 in | 2 |
| 破洞 > 1 in | 4 |

**判定**：每 100 线性码的平均疵点分。客户限值通常 ≤ 28 或 ≤ 40 分/100 码，具体按合同。

四分制与 AQL 的关键区别：
- AQL 是"合格/不合格"的批量接受方案，四分制是"严重程度加权"的连续评估
- 面料可以同时用四分制（逐卷评分）和 AQL（按批量的卷数判定接收/拒收）
- 参考 [RM-007](case:RM-007) 中四分制疵点从 42 降至 18 的案例

## 五、 抽检方案设计的常见误区

| 误区 | 正确理解 |
| :--- | :--- |
| "AQL 2.5 意味着 2.5% 的不良品是可以接受的" | AQL 是过程平均质量的风险阈值，不是单批的不良率上限 |
| "抽检通过 = 这批货没问题" | 抽检是概率决策，AQL 2.5 / n=80 的方案对 5% 不良率的漏检概率约 25% |
| "加大样本量就能抓到所有问题" | 样本量翻倍只能适度提高检出力，不能替代过程控制 |
| "所有产品用同一个 AQL" | 应按品类风险和供应商历史质量分级，参考 [SYS-009](case:SYS-009) |
| "Tightened 是惩罚" | Tightened 是风险管理工具，帮助在质量下降时提前拦截 |
| "跳批（Skip-Lot）是免检" | 跳批仍有定期抽检（如每 5 批抽 1 批），且前提是 DQA 授权 + 连续合格记录 |

## 六、 特殊场景的抽检考量

### 6.1 小批量 / 多款少量

快时尚和电商常见单款 200–500 件的小批量。Z1.4 在小批量时样本量与批量之比很高（如批量 200，Normal/II 样本 32，即 16%），成本高。选项：
- 保持 Normal/II 不变（安全但贵）
- 对低风险款降到 Level I（样本约 13，减少 60%）
- 对高风险小批量反而应考虑 100% 检验

### 6.2 破坏性测试

撕破、顶破、燃烧、色牢度等测试会消耗试样。使用 S-1 至 S-4 特殊检验水平，每批 2–8 个试样，配合型式测试（首批全测 + 后续抽测）。

### 6.3 面辅料来料检验

面辅料的抽检方案应与成品分开设计。参考 [SOP-DFQ](doc:SOP-DFQ) 的面料准入要求和 [SYS-009](case:SYS-009) 的风险分级模型。
