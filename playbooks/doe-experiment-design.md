# 纺织服装 DOE 实验设计模板

> **Design of Experiments (DOE) for Textile Process Optimization**

---

## 一、 为什么纺织工艺优化需要 DOE

传统的"一次改一个变量"（OFAT）方法在纺织工艺中效率低且容易遗漏交互作用。例如：
- 压烫温度和压力对粘合衬剥离强力的影响不是独立的——最优温度取决于压力水平
- 染色温度、时间、助剂浓度三个因子对色牢度的联合影响无法通过单独调整某一个来发现

DOE 通过系统地同时变化多个因子，用最少的实验次数获取最多的信息，并量化因子间的交互作用。

**案例库中的 DOE 应用**：[RM-008](case:RM-008) 使用 DOE 优化 C0 DWR 整理工艺（3 因子 2 水平全因子设计 + 中心点）。

---

## 二、 DOE 类型选择

| DOE 类型 | 因子数 | 实验次数 | 适用场景 |
| :--- | :--- | :--- | :--- |
| **全因子设计（Full Factorial）** | 2–4 | $2^k$ 至 $3^k$ | 因子少、需要完整的交互信息 |
| **部分因子设计（Fractional Factorial）** | 5–8 | $2^{k-p}$ | 因子多、先筛选关键因子 |
| **中心复合设计（CCD）** | 2–5 | $2^k + 2k + c$ | 需要拟合二次响应曲面、找最优点 |
| **Taguchi 正交表** | 3–13 | L9/L18 等 | 噪声因子已知、追求稳健设计 |
| **Plackett-Burman** | ≤ 11 | 12 次 | 纯筛选，不估计交互 |

**纺织领域推荐路径**：
1. 因子 ≤ 4 且资源允许 → **全因子 + 中心点**（如 [RM-008](case:RM-008)）
2. 因子 5–8 且不确定哪些重要 → **部分因子筛选** → 对关键因子做全因子
3. 需要找最优工艺参数 → **CCD 响应曲面**

## 三、 DOE 实施六步

### Step 1: 定义目标与响应变量

| 要素 | 说明 | 示例（DWR 优化） |
| :--- | :--- | :--- |
| **目标** | 用一句话说明要优化什么 | 在保持 C0 DWR 初始拒水性 ≥ 90 分的前提下，最大化 20 次洗涤后的拒水性 |
| **响应变量（Y）** | 可测量的输出 | AATCC 22 喷淋评级（0–100） |
| **测量方法** | 响应变量的测试标准 | AATCC 22，20 次 AATCC 135 洗涤后 |

响应变量必须是 `registry/metrics.json` 中已定义的指标，或在 DOE 前先登记。

### Step 2: 选择因子与水平

| 因子 | 类型 | 低水平 (−) | 高水平 (+) | 选择依据 |
| :--- | :--- | :--- | :--- | :--- |
| A: DWR 浓度 | 连续 | 30 g/L | 60 g/L | 供应商推荐范围 |
| B: 焙烘温度 | 连续 | 150°C | 170°C | 面料耐温上限 |
| C: 焙烘时间 | 连续 | 60 s | 90 s | 产线速度约束 |

**水平选择原则**：
- 范围要够大，让效应可被检测到（信号 > 噪声）
- 但不能超出设备能力或产品安全限制
- 中心点可加 3–5 个，用于检测曲率和估计纯误差

### Step 3: 确定实验方案

3 因子 2 水平全因子 + 3 个中心点 = **11 次实验**。

| Run | A: 浓度 | B: 温度 | C: 时间 | 随机顺序 |
| :---: | :---: | :---: | :---: | :---: |
| 1 | − | − | − | 7 |
| 2 | + | − | − | 3 |
| 3 | − | + | − | 11 |
| 4 | + | + | − | 1 |
| 5 | − | − | + | 9 |
| 6 | + | − | + | 5 |
| 7 | − | + | + | 2 |
| 8 | + | + | + | 8 |
| 9 | 0 | 0 | 0 | 4 |
| 10 | 0 | 0 | 0 | 6 |
| 11 | 0 | 0 | 0 | 10 |

**关键纪律**：
- **完全随机化**：按"随机顺序"列执行，不按 Run 编号顺序
- **每次实验独立取样**：不能从同一块布上切 11 个样（除非布内均匀性已由 MSA 验证）
- **环境条件记录**：每次实验的环境温湿度、设备状态

### Step 4: 执行实验并记录数据

每次实验记录：
- 因子实际值（不只是设定值——如设定 170°C 但实际 168°C，记 168）
- 响应变量测量值（每个条件至少重复测 2–3 个试样取平均）
- 异常记录（设备故障、操作偏差）

### Step 5: 分析结果

| 分析工具 | 用途 |
| :--- | :--- |
| **效应图（Main Effects Plot）** | 每个因子的主效应大小和方向 |
| **交互作用图（Interaction Plot）** | 因子间是否存在交互（线交叉 = 有交互） |
| **ANOVA 表** | 因子/交互的 p 值（p < 0.05 为显著） |
| **正态概率图** | 残差检验——模型是否合理 |
| **响应曲面图** | 寻找最优工艺窗口（CCD 时用） |

**纺织 DOE 常见发现**：
- 温度 × 时间的交互几乎总是显著（高温短时 ≈ 低温长时，但极端组合有风险）
- 浓度的主效应通常最大，但有饱和点（超过某浓度后无额外收益）

### Step 6: 确认实验（Confirmation Run）

用分析得出的最优条件做 **3–5 次独立确认实验**，验证：
- 响应均值落在预测的置信区间内
- 工艺在生产条件下可重复

确认失败 → 检查模型假设、噪声因子、或扩大实验范围。

## 四、 纺织 DOE 的特殊注意事项

### 4.1 面料均匀性

面料不是均匀材料——经纬向、头中尾、左中右都可能不同。DOE 的试样取样必须控制位置变异：
- 所有试样从同一卷的相邻位置取
- 或将位置作为"区组（Block）"因子纳入设计

### 4.2 破坏性测试

很多纺织测试（撕破、起球、色牢度）是破坏性的，同一试样不能重复测试。解决方法：
- 每个实验条件准备足够多的试样（响应变量个数 × 重复次数）
- 用 Split-Plot 设计处理"整块面料做整理 → 再切试样测不同响应"的嵌套结构

### 4.3 批次间变异

如果 DOE 跨批次面料执行（如筛选实验持续数天），批次差异可能掩盖工艺因子的效应。对策：
- 尽可能用同一批次面料
- 如必须跨批次，将批次作为区组因子

### 4.4 工厂端执行

DOE 通常在实验室或试产线上执行，但最终要在大货产线上确认。工厂端的噪声（操作员变异、设备波动）可能使实验室最优条件失效——确认实验必须在实际生产条件下做。

## 六、 DOE 与其他质量工具的关系

| 工具 | 与 DOE 的关系 |
| :--- | :--- |
| [PB-FMEA](doc:PB-FMEA) | FMEA 中的高 RPN 项 → 用 DOE 找根因和最优工艺 |
| [PB-SPC](doc:PB-SPC) | DOE 找到最优参数后 → 用 SPC 监控过程稳定性 |
| [PB-MSA](doc:PB-MSA) | DOE 前 → 必须确认测量系统可用（GRR %Study Var ≤ 10% 优秀，10–30% 勉强可用，> 30% 不合格），否则响应变量的噪声来自测量而非工艺 |
| [PB-RCA](doc:PB-RCA) | RCA 锁定根因因子 → DOE 量化因子效应并优化 |
| DMAIC | DOE 通常在 DMAIC 的 Improve 阶段使用 |
