# 纺织服装测量系统分析（MSA）与 Gage R&R 模板

> **Measurement System Analysis & Gage R&R for Textile Testing**

---

## 一、 为什么纺织测试尤其需要 MSA

纺织品测试的变异来源比金属加工更复杂：试样取样位置、温湿度调湿、测试员操作手法、仪器校准状态都会影响结果。如果测量系统本身的变异占总变异的大比例，SPC 控制图和 Cpk 就没有意义——你在监控的是测量噪声，不是过程。

[SYS-004](case:SYS-004) 的实验室间比对案例就展示了这一问题：同一盲样在不同实验室的色牢度评级差异高达 1.5 级。

---

## 二、 MSA 五性

| 特性 | 定义 | 纺织测试中的体现 |
| :--- | :--- | :--- |
| **偏倚（Bias）** | 测量均值与真值之差 | 实验室的灰卡评级系统性偏高或偏低 |
| **线性（Linearity）** | 偏倚随测量范围的变化 | 拉力机在低力值和高力值下准确度不同 |
| **稳定性（Stability）** | 偏倚随时间的变化 | 染色打样灯箱灯管老化导致目视判定漂移 |
| **重复性（Repeatability）** | 同一测试员、同一仪器、同一试样多次测量的变异 | 同一验布员对同一段面料连续两次四分制评分的差异 |
| **再现性（Reproducibility）** | 不同测试员（或不同仪器、不同实验室）对同一试样的变异 | 不同实验室对同一盲样的色牢度评级差异 |

---

## 三、 Gage R&R 研究设计

### 3.1 连续型数据：交叉 Gage R&R（ANOVA 法）

适用于撕破强力、顶破强力、面料克重、成衣尺寸等连续型指标。

**实验设计**：
- **零件（Parts）**：选取 ≥ 10 个代表性样品，覆盖规格范围（不能全选中间值）
- **操作员（Operators）**：≥ 2 名（理想 3 名），代表日常操作的人员范围
- **重复（Replicates）**：每个操作员对每个样品测量 ≥ 2 次（理想 3 次）
- **随机化**：测量顺序完全随机，操作员不能看到前一次的结果

**示例**：3 名测试员 × 10 个面料样品 × 3 次重复 = 90 次测量

### 3.2 判定标准

| 指标 | 公式 | 合格 | 边界 | 不合格 |
| :--- | :--- | :---: | :---: | :---: |
| **%Study Var（GRR/TV）** | $\frac{\sigma_{GRR}}{\sigma_{TV}} \times 100\%$ | ≤ 10% | 10–30% | > 30% |
| **%Tolerance（GRR/Tol）** | $\frac{6\sigma_{GRR}}{USL - LSL} \times 100\%$ | ≤ 10% | 10–30% | > 30% |
| **ndc（可区分类别数）** | $\frac{\sigma_{Parts}}{\sigma_{GRR}} \times 1.41$ | ≥ 5 | 3–4 | < 3 |

- **%Study Var ≤ 10%**：测量系统优秀，可用于 SPC 和 Cpk
- **10–30%**：勉强可用，取决于应用场景和改善成本
- **> 30%**：测量系统不合格，必须改善后重新评估——此时 Cpk 无意义

### 3.3 等级型数据：属性一致性分析（Attribute Agreement Analysis）

适用于色牢度灰卡评级、起球等级、外观检验合格/不合格判定等序数型或二值型数据。

**实验设计**：
- **样品**：≥ 30 个，覆盖各等级（含边界样品）
- **评定员**：≥ 2 名
- **重复**：每个评定员对每个样品独立评定 ≥ 2 次
- **标准答案**：由专家小组预先确定每个样品的"真实"等级

**判定指标**：
- **评定员内一致性**：同一评定员两次评定一致的比例（目标 ≥ 90%）
- **评定员间一致性**：所有评定员评定相同的比例（目标 ≥ 80%）
- **与标准一致性**：评定员与专家标准一致的比例（目标 ≥ 85%）
- **Cohen's kappa**：校正随机一致后的一致性系数（kappa ≥ 0.80 为良好）

参考 [SYS-004](case:SYS-004) 的实验室间比对案例和 [SYS-001](case:SYS-001) 的 DQA 盲样考核。

## 四、 纺织测试 MSA 的特殊注意事项

### 4.1 试样的不可重复性

很多纺织测试是破坏性的（撕破、顶破、起球），同一试样无法重复测量。解决方法：
- 从同一批面料的相邻位置取多个试样，假设这些试样之间的差异主要来自面料本身的局部变异而非测量系统——这个假设要求取样位置尽可能相近
- 用嵌套设计（Nested GRR）替代交叉设计：每个操作员测不同试样，ANOVA 中零件与操作员不交叉

### 4.2 调湿条件

纺织品的物理性能受温湿度影响显著（ASTM D1776 标准大气 21℃ / 65% RH）。MSA 前确认：
- 所有试样在同一调湿室调湿至少 4 小时（含水率依赖型测试如棉织物可能需要更长）
- 测试环境温湿度在允差内

### 4.3 灰卡评级的主观性

灰卡评级（色变、沾色）主观性强，是纺织 MSA 中再现性最差的项目之一：
- 光源必须一致（D65 + 指定次光源），灯箱灯管使用超过 2,000 小时或制造商建议的寿命应更换
- 评定员每年做视力检查（色觉正常）
- 用物理灰卡标准片校准，不依赖"经验"

## 五、 MSA 频率与触发条件

| 触发条件 | 频率 | 范围 |
| :--- | :--- | :--- |
| 新仪器投用 | 投用前 | 完整 Gage R&R |
| 仪器大修或校准 | 修后 | 偏倚 + 重复性验证 |
| 新测试员上岗 | 上岗前 | 加入现有 Gage R&R 作为新操作员 |
| 年度复审 | 每年 | 关键指标（用于 SPC/Cpk 的指标）完整 Gage R&R |
| SPC 控制图异常 | 事件触发 | 排除测量系统原因 |
| 实验室间比对发现差异 | 事件触发 | 属性一致性分析 + Gage R&R |
