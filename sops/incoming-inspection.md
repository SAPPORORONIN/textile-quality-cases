# 面辅料来料检验标准作业程序

> **Incoming Quality Control (IQC) SOP for Fabrics, Trims & Accessories**

---

## 一、 目的与适用范围

### 1.1 目的

规范面料、辅料、包装材料的来料检验流程，在投产前拦截不合格原材料，降低成品缺陷率和返工成本。

### 1.2 适用范围

- 所有外采面料（梭织、针织、功能性面料）
- 辅料（粘合衬、拉链、纽扣、弹力带、缝纫线、标签、吊牌）
- 包装材料（塑料袋、纸箱、填充物）

### 1.3 引用文件

- [SYS-009](case:SYS-009) — 风险分级动态 AQL 抽检方案
- [PB-AQL](doc:PB-AQL) — AQL 抽检方案设计手册
- [RM-005](case:RM-005)–[RM-008](case:RM-008) — 原辅料质量案例
- ASTM D5430 — 四分制面料检验
- AATCC 评估程序系列 — 色牢度灰卡评级
- 16 CFR 1610 — 服装面料燃烧性测试
- CPSIA Sec. 101 — 儿童产品铅含量限值

## 二、 来料分类与检验等级

### 2.1 物料风险分类

| 风险等级 | 定义 | 典型物料 | 检验强度 |
| :--- | :--- | :--- | :--- |
| **A — 高风险** | 直接影响安全/法规合规，或对成品外观质量有决定性影响 | 面料（全部）、粘合衬、儿童产品辅料 | 每批必检 + 实验室测试 |
| **B — 中风险** | 影响成品功能或外观，但有行业通用规格 | 拉链、纽扣、弹力带、缝纫线 | 每批抽检，按 AQL 方案 |
| **C — 低风险** | 不直接影响产品质量 | 吊牌、纸箱、塑料袋、填充物 | 首批检验 + 后续跳批 |

### 2.2 供应商质量等级联动

来料检验强度与供应商的质量等级挂钩（参考 [SYS-009](case:SYS-009) 的风险分级模型）：

| 供应商等级 | 正常检验 | 加严条件 | 跳批条件 |
| :--- | :--- | :--- | :--- |
| **优选（Skip-Lot 资格）** | 每 5 批抽 1 批 | 1 批不合格即恢复 Normal | 连续 20 批合格 + DQA 授权 |
| **合格（Normal）** | 每批按 Normal/II | 连续 5 批中 2 批不合格 → Tightened | — |
| **观察（Tightened）** | 每批按 Tightened/II | 连续 5 批不合格 → 暂停供货 | 连续 5 批合格 → Normal |
| **新供应商** | 首 3 批 100% 检验 + 全项测试 | — | — |

## 三、 面料来料检验流程

### 3.1 收货与初步核查

1. **单据核查**：核对装箱单（Packing List）与 PO 的品名、颜色、数量、批次号（Lot#）是否一致
2. **外包装检查**：运输损坏（水渍、破损、压痕）记录并拍照
3. **卷标信息**：核对每卷的布号、颜色号、缸号、卷长、克重标注与供应商的检验报告是否一致

### 3.2 面料外观检验（四分制）

按 ASTM D5430 四分制检验：

- **抽检比例**：
  - A 类面料 / Tightened 供应商：≥ 30% 的卷数
  - Normal 供应商：≥ 15% 的卷数
  - Skip-Lot 供应商：≥ 5% 的卷数（或按跳批频率）
- **检验速度**：验布机速度 ≤ 15 码/分钟（深色 / 精细面料 ≤ 10 码/分钟）
- **判定标准**：每 100 线性码的平均疵点 ≤ 客户指定限值（通常 ≤ 28 或 ≤ 40 分/100 码）
- **记录**：每卷的疵点位置、类型、扣分记录在验布报告中，扫描存档

### 3.3 面料物理/化学测试

| 测试项目 | 测试方法 | 频率 | 适用条件 |
| :--- | :--- | :--- | :--- |
| 克重 | ASTM D3776 | 每批 | 全部面料 |
| 色差（与确认样对比） | AATCC 173 / 仪器 ΔE | 每缸 | 染色面料 |
| 缩水率 | AATCC 135 / 150 | 每批（新供应商每缸） | 全部面料 |
| 色牢度（水洗、摩擦） | AATCC 61 / 8 | 每批 | 染色面料 |
| 撕破强力 | ASTM D1424 | 每批 | 梭织面料 |
| 顶破强力 | ASTM D3786 | 每批 | 针织面料 |
| 甲醛含量 | AATCC 112 | 首批 + 年度复测 | 全部面料 |
| 铅含量 | CPSC-CH-E1001 | 首批 + 年度复测 | 儿童产品面料 |
| 燃烧性 | 16 CFR 1610 | 首批 + 年度复测 | 服装面料 |
| 拒水性 | AATCC 22 | 每批 | 功能性拒水面料 |
| pH | AATCC 81 | 首批 + 年度复测 | 全部面料 |

**说明**：
- "首批"指该面料品种（品名 + 成分 + 供应商）首次来料；
- 供应商提供的测试报告可作为参考但不能替代品牌自测——除非该供应商的实验室已通过 MSA 比对且 kappa ≥ 0.80（参考 [PB-MSA](doc:PB-MSA)）。

### 3.4 面辅料特殊检验项

| 辅料类型 | 检验重点 | 参考案例 |
| :--- | :--- | :--- |
| **粘合衬** | 粘合剥离强力（180° 剥离 ≥ 客户最低值）、缩水率、与面料配伍性 | [RM-005](case:RM-005) |
| **拉链** | 拉合顺畅度、横拉强力、拉头松紧、颜色匹配 | — |
| **纽扣** | 拉力测试（≥ 15 lbs，ASTM D7842）、颜色/光泽匹配、儿童产品小部件测试 | — |
| **弹力带** | 拉伸回复率、耐洗次数后回缩、宽度公差 | — |
| **缝纫线** | 线号/颜色确认、断裂强力、缩水率 | — |
| **标签/吊牌** | 内容准确性（RN 号、成分、产地、洗涤指示）、粘合牢度 | — |

## 四、 不合格品处置

### 4.1 判定等级

| 等级 | 定义 | 处置 |
| :--- | :--- | :--- |
| **接收** | 全部检验项合格 | 入库、放行使用 |
| **有条件接收** | 轻微偏差但不影响成品质量（如色差 ΔE 在限值边界） | QA 经理审批 + 记录偏差 + 加密监控 |
| **拒收** | 任一关键项不合格 | 隔离 + 供应商 8D + 退/换货 |
| **暂扣** | 需要补充测试才能判定 | 隔离等待结果，不得先行投产 |

### 4.2 不合格处理流程

1. **隔离**：不合格品在仓库中物理隔离并标记红色标签，WMS 中锁定状态
2. **通知供应商**：24 小时内发出不合格通知（NCR），附检验报告和照片
3. **8D 要求**：Major / Critical 不合格要求供应商在规定时限内提交 8D 报告（参考 [SYS-011](case:SYS-011) 的 SLA 要求）
4. **退/换货**：拒收批次在 5 个工作日内安排退货或换货
5. **记录**：不合格记录纳入供应商质量档案，影响质量等级评定

## 五、 记录与数据管理

### 5.1 必须保留的记录

| 记录 | 保存期限 | 格式 |
| :--- | :--- | :--- |
| 验布报告（四分制评分） | 3 年 | 电子 + 扫描件 |
| 实验室测试报告 | 5 年 | 电子 |
| 不合格通知（NCR） | 5 年 | 电子 |
| 有条件接收审批记录 | 3 年 | 电子 |
| 面料色样/确认样 | 当季 + 1 年 | 实物 |

### 5.2 数据用途

- 来料合格率按月汇总，纳入供应商质量记分卡
- 不合格模式（失效类型 × 供应商 × 物料）的 Pareto 分析，季度评审时呈现
- 四分制疵点趋势用 u-chart 监控（参考 [PB-SPC](doc:PB-SPC)）
