# 产前会（Pre-Production Meeting）标准作业程序

> **Pre-Production Meeting (PPM) SOP**

---

## 一、 目的与适用范围

### 1.1 目的

规范产前会的召开时机、参与角色、标准议程、红旗暂缓规则和行动追踪机制，使产前会从"走形式"变为量产前的风险拦截关键门禁。

### 1.2 适用范围

所有品牌 PO 在开裁前必须召开产前会。以下情况可豁免：
- 同一工厂 × 同一款式 × 同一面辅料的重复翻单（非首单），且上一单 FTR 合格 → 可改为简化版产前会（仅确认变更点）

## 二、 产前会召开时机

| 事件 | 产前会时机 |
| :--- | :--- |
| 新款首单 | 面辅料到齐 + 产前样确认后，**开裁前 ≥ 3 个工作日** |
| 翻单（有变更） | 变更点确认后，**开裁前 ≥ 2 个工作日** |
| 翻单（无变更，豁免） | 简化版确认（邮件或电话），不要求正式会议 |

---

## 三、 必须参加角色

### 3.1 工厂端（必须到场）

| 角色 | 职责 | 缺席时 |
| :--- | :--- | :--- |
| 品质经理（主持） | 主持会议、记录结论 | 不可缺席 |
| 生产计划主管 | 确认排产计划、交期可行性 | 可委托副手 |
| 裁剪车间主管 | 确认面料铺布排料方案、面料损耗 | 不可缺席 |
| 缝制车间主管 | 确认工艺难点、缝制顺序 | 不可缺席 |
| 特殊工艺主管 | 印花/绣花/水洗/粘合等（视产品而定） | 有特殊工艺时不可缺席 |

### 3.2 品牌端

| 角色 | 职责 |
| :--- | :--- |
| **QA 工程师**（非初级 QC） | 风险评估、红旗判定、QCP 联动 |
| 采购员（可远程） | 交期确认、商务问题协调 |

## 四、 标准议程与必检清单

### 4.1 八项必检清单

| 序号 | 议程项 | 检查内容 | 红旗规则（任一触发 → 暂缓开裁） |
| :---: | :--- | :--- | :--- |
| 1 | **面料确认** | 大货面料与确认样对比（色差、手感、克重、缩水） | ΔE (CMC 2:1, D65/10°) > 1.0 或克重偏差 > 5% 或缩水超差 |
| 2 | **辅料确认** | 粘合衬、拉链、纽扣、弹力带等实物核对 | 任一辅料未到齐或与确认样不符 |
| 3 | **面辅料配伍** | 粘合衬压烫试验、拉链色差、弹力带缩水匹配 | 剥离强力 < 最低值或缩水率差异 > 2% |
| 4 | **尺寸与版型** | Tech Pack 最新版确认、放码表核对、产前样关键尺寸 | 产前样关键尺寸偏差 > 1 cm |
| 5 | **特殊工艺** | 印花/绣花/水洗参数确认、试产样确认 | 无试产样或试产样未获批准 |
| 6 | **法规合规** | 标签内容、测试计划/状态、CPC 要求（儿童产品） | 关键测试未完成或标签有误 |
| 7 | **包装** | 折叠方式、吊牌位置、箱唛规格、条码 | 未确认 |
| 8 | **历史教训** | 查案例库：同工厂 / 同品类 / 同面料的历史质量问题 | 同类问题的纠正措施未验证 |

### 4.2 红旗暂缓机制

- 任一红旗规则触发 → 产前会结论为**暂缓开裁**
- QA 工程师有权签发暂缓指令，无需请示总监
- 暂缓原因、预期解决时间、责任人记录在系统中
- 红旗解除后，QA 工程师签字确认方可开裁

## 五、 行动追踪

### 5.1 行动项记录

产前会产生的每条行动项录入质量管理系统：
- **描述**: 具体问题和需要做什么
- **责任人**: 姓名（不是部门）
- **完成日期**: 必须在开裁前
- **状态**: 待处理 / 进行中 / 已关闭

### 5.2 自动提醒

- 开裁日前 **3 天**: 系统自动提醒所有未关闭行动项的责任人
- 开裁日前 **1 天**: 仍有未关闭行动项 → 自动通知 QA 经理
- 开裁日: 仍有未关闭的红旗级别行动项 → **自动触发暂缓**

## 六、 QCP 联动

产前会的风险发现直接写入该 PO 的质量控制计划（QCP）：

| 产前会发现 | QCP 动作 |
| :--- | :--- |
| 面辅料配伍风险 | 增加首件压烫确认点 |
| 特殊工艺高风险 | 对应工序从抽检改为全检或增加检验频次 |
| 面料四分制边界合格 | 裁剪工序增加面料复验点 |
| 历史教训相关 | 针对历史问题点增加专项检验 |
| 新供应商/新面料 | 加密在线检验频次 |

参考 [playbooks/control-plan.md](doc:PB-QCP) 的 QCP 编制方法。
